## ⚖️ Decisions Made

1. **In-House Takeover of Phase 26 [A-006, A-008]**:  
   After detecting that Jules's PR #9 omitted database migration 0010, route handlers, and integration tests, we took over the implementation in-house rather than burning cycles attempting remote repair prompts.
2. **Relational Stamping Outside Encrypted Metadata Columns [A-006, A-008]**:  
   Stored `import_batch_id` and `imported_at` as plaintext indexed columns in SQLite, deliberately excluding them from `METADATA_COLUMNS`. This preserves Layer 1/2 cryptographic isolation while allowing $O(1)$ batch lookups, bulk graduation, and cascading reverts.
3. **Auto-Graduation on Edit Invariant [A-008, A-009]**:  
   Updating any record (`PUT /api/vault/:id`, `PUT /api/notes/:id`, `PUT /api/ssh-keys/:id`) unconditionally nullifies `import_batch_id` and `imported_at`, permanently adopting the secret into the primary vault.
4. **Progressive Disclosure UI Pattern [A-008, A-009]**:  
   Zero quarantine UI elements, filter chips, countdowns, or batch action bars render unless active unexpired imported records exist in state, keeping the vault workspace noise-free.
5. **Dedicated Troubleshooting Hub [A-011, A-012]**:  
   Consolidated previously fragmented failure-mode documentation into a centralized, searchable guide at `docs/getting-started/troubleshooting.md`, indexed across both web and mobile sidebars.

## 💥 Assumptions That Broke

1. **Assumption: Cloud CI Passing Implies Complete Implementation [A-006]**:  
   - *Broken by*: PR #9 passed 100% green on GitHub Actions, but a line-by-line git tree comparison revealed that none of the backend schema, API, or test files existed in the commit. Existing test suites had simply run against an un-migrated codebase.
   - *Replacement*: Mandatory line-by-line diff audit against target base prior to review acceptance.
2. **Assumption: Deep Architectural Docs Are Sufficient for First-Time Users [A-011]**:  
   - *Broken by*: The cold user simulation revealed that while technical depth was outstanding, a newcomer lacked basic muscle-memory instructions on how to add a password in the UI, had no direct APK link to install the mobile app, and had to guess where connection troubleshooting was documented.
   - *Replacement*: The 4-step UI action walkthrough in `the-grotto.md`, direct latest APK links in `mobile/index.md`, and the centralized `troubleshooting.md` portal.
