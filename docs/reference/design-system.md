# Reef Modernist Design System

<CopyPage />

The ShellGuard aesthetic, dubbed **"Bioluminescent Defense"**, marries deep ocean dark surfaces with high-visibility glowing accent neon.

---

## 🎨 Color Palette

| Token | Hex | Role | Usage |
|---|---|---|---|
| **Abyssal Base** | `#080c14` | Background canvas | Root viewport and outer margins |
| **Abyssal Surface** | `#0f172a` | Container surface | Cards, tables, modals |
| **Lobster Pink** | `#e4048a` | Brand primary | Hero marks, primary CTAs, active indicators |
| **Bioluminescent Cyan** | `#06b6d4` | Secondary energy | Security pills, code highlights, tooltips |
| **Emerald Guard** | `#10b981` | Success state | Active sessions, verified checks, healthy state |
| **Danger Red** | `#ef4444` | Destruction state | Cascade delete buttons, error alerts |

---

## 🔤 Typography

- **Display & Headings**: `Sora`, `Switzer`, or `Inter` (geometric, modern, authoritative).
- **Body Text**: `Inter` / `Geist` (high legibility at small sizes).
- **Code & Keys**: `JetBrains Mono` / monospace (tabular numbers for keys and hashes).

---

## 🌊 Spring Physics & Micro-Interactions

Components utilize Framer Motion springs (`stiffness: 400`, `damping: 30`) for snappy, tactile UI responses without sluggish easing curves.
