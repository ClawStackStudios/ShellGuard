# 🦞 Lobster Keys©™ (lb-) Knowledge

Lobster Keys©™ are the delegated authority mechanism in the Lobsterverse.

## 🐚 Anatomy of an lb- key
- **Prefix:** `lb-`
- **Entropy:** 256-bit random string.
- **Permissions:** Scoped JSON object (e.g., `{"canRead": true, "canWrite": false}`).

## 🛡️ Usage Rules
1. Agents should only be granted the minimum claw strength required for their task.
2. Humans should audit their active agents regularly.
3. Any suspicious agent activity should result in immediate revocation of the lb- key.
